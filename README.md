# brozen AI — Telegram AI Shop Bot

ربات فروش اشتراک/پلن هوش مصنوعی با پنل ادمین داخل تلگرام، پرداخت دستی با تأیید ادمین، مدیریت پلن‌ها و مصرف اعتبار.

## امکانات
- خوش‌آمدگویی و منوی حرفه‌ای فارسی
- ثبت‌نام خودکار کاربران
- پلن‌های قابل ساخت/ویرایش/حذف از پنل ادمین
- قیمت، مدت، اعتبار پیام، توضیحات و فعال/غیرفعال کردن پلن
- سفارش و پرداخت دستی
- ارسال رسید به ادمین‌ها + تأیید/رد با دکمه
- اعمال خودکار اشتراک پس از تأیید
- کد تخفیف درصدی
- کیف حساب و سابقه سفارش
- چت با مدل AI با حفظ تاریخچه کوتاه
- محدودیت اعتبار بر اساس پلن
- آمار، کاربران، سفارش‌ها و تنظیمات
- تغییر شماره کارت، نام صاحب حساب و متن‌های اصلی از پنل
- SQLite برای شروع؛ قابل مهاجرت به PostgreSQL
- health endpoint برای Railway
- لاگ و مدیریت خطا

## Railway
1. Repo را به GitHub بفرست.
2. Railway → New Project → Deploy from GitHub Repo.
3. Variables را از `.env.example` بساز.
4. Start Command: `python bot.py`
5. این سرویس باید به‌صورت دائمی اجرا شود، نه Cron.

Railway متغیرها را در زمان اجرا به برنامه می‌دهد و برای secretها از Variables استفاده کن.

## متغیرهای لازم
- `BOT_TOKEN`
- `OPENAI_API_KEY`
- `ADMIN_IDS`

## نکته پرداخت
این نسخه «پرداخت دستی + رسید + تأیید ادمین» دارد. درگاه بانکی واقعی جدا از این است و برای اتصال به درگاه باید API همان درگاه و callback رسمی آن اضافه شود.
